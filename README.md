# DIGI Learn

### Open-Source Learning Platform for Class 1–5

DIGI Learn is an open-source educational web application built by **Eren × Thunderzz**. It is designed to provide a simple and structured digital learning experience for students from Class 1 to Class 5.

## Features

* Class 1–5 learning system
* Mathematics, English, Punjabi, Science and Social Science
* Video lectures, notes and short notes
* English and Punjabi language support
* Pomodoro study timer
* XP and level system
* Daily study goals and streaks
* Progress tracking and achievements
* Leaderboard
* Study Together and virtual study rooms
* Responsive design for desktop and mobile
